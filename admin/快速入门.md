# 快速入门（半小时入门后端）

## 前置知识

### 什么是 Spring Boot？

Spring Boot 是一个 **Java Web 开发框架**，可以快速创建独立的、基于 Spring 的应用程序。

**简单理解**：
- 你写 Java 代码
- Spring Boot 自动帮你配置好服务器（Tomcat）
- 运行 main() 方法就能启动一个 Web 服务

---

## 第一个概念：分层架构

后端代码分为 **三层**：

```
┌─────────────────────────────────────┐
│          Controller（控制层）          │
│   接收请求、返回响应                   │
└─────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────┐
│           Service（服务层）            │
│   处理业务逻辑                        │
└─────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────┐
│         Repository（数据层）           │
│   操作数据库                          │
└─────────────────────────────────────┘
```

**类比餐厅**：
- Controller = 服务员（接待客人、记录点单）
- Service = 厨师（炒菜、处理）
- Repository = 采购（拿食材、存食材）

---

## 第二个概念：请求流程

当你访问 `GET /api/user/info?userId=1` 时：

```
1. 前端发送请求
   GET http://localhost:8080/api/user/info?userId=1

2. JwtInterceptor（拦截器）处理
   - 检查有没有 Token
   - Token 过期了吗？
   - 没过期就放行

3. Controller（控制器）接收
   @GetMapping("/info")
   public Result<UserInfoVO> getUserInfo(@RequestParam Long userId) {
       // 接收参数 userId = 1
   }

4. Service（服务）处理业务
   - 查询数据库有没有这个用户
   - 返回用户信息

5. AOP 切面记录日志
   - 记录：谁访问的、参数是什么、花了多久

6. 返回响应给前端
   {"code": 200, "message": "操作成功", "data": {...}}
```

## 第四个概念：实体类

**为什么需要 User、UserDTO、UserVO 三个类？**

| 类 | 作用 | 示例 |
|---|------|------|
| User（PO） | 对应数据库表 | 有 password 字段 |
| UserDTO | 接收前端参数 | 登录只需要 username + password |
| UserVO | 返回给前端 | 不能有 password！ |

**想象餐厅点餐**：
- 你告诉服务员要点"宫保鸡盒"（DTO，只给需要的）
- 厨房去仓库拿食材（PO，完整的）
- 服务员给你上菜（VO，你只需要知道菜好不好吃）

## 第五个概念：AOP 切面

**AOP = 拦截器 + 额外逻辑**

```java
@Aspect
@Component
public class ControllerLogAspect {

    @Around("execution(* com.example.controller..*.*(..))")
    public Object around(ProceedingJoinPoint joinPoint) {
        // 方法执行前：记录日志
        log.info("开始调用: {}", methodName);

        // 执行原方法
        Object result = joinPoint.proceed();

        // 方法执行后：记录日志
        log.info("结束调用，耗时: {}ms", costTime);

        return result;
    }
}
```

**效果**：所有 Controller 被调用时，自动记录日志，不用在每个方法里手动加。

## 第六个概念：JWT Token

**JWT = 身份证**

用户登录成功后，服务器发给他一张"身份证"（Token）

```
Token 长这样：
eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiIxMjM0NTY3ODkwIn0.abc123...

实际是加密的字符串，包含：
{
  "sub": "1234567890",   // 用户 ID
  "iat": 1516239022,     // 签发时间
  "exp": 1516325422      // 过期时间
}
```

**为什么用它？**
- 不需要 session（服务器不存储）
- Token 带着走，放在请求头里
- 服务器验证 Token 就能知道是谁

## 下一步学什么？

### 1. 添加新接口

**步骤**：
1. 在 `UserController.java` 加新方法
2. 在 `UserService.java` 加接口
3. 在 `UserServiceImpl.java` 实现
4. 重启项目

**示例**：添加"修改密码"接口

```java
// Controller
@PostMapping("/updatePassword")
public Result<Void> updatePassword(@RequestBody Map<String, String> params) {
    userService.updatePassword(params.get("oldPwd"), params.get("newPwd"));
    return Result.success();
}

// Service
public interface UserService {
    void updatePassword(String oldPwd, String newPwd);
}

// ServiceImpl
@Override
public void updatePassword(String oldPwd, String newPwd) {
    // 1. 校验旧密码
    // 2. 更新新密码
    // 3. 返回
}
```

### 2. 添加新表

**步骤**：
1. 在 `init.sql` 加建表语句
2. 创建 PO 类（对应表）
3. 创建 Repository 接口
4. 创建 Service
5. 创建 Controller

**示例**：添加商品表

```sql
CREATE TABLE sys_product (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    price DECIMAL(10,2),
    create_time DATETIME
);
```

```java
@TableName("sys_product")
public class Product {
    private Long id;
    private String name;
    private BigDecimal price;
    private LocalDateTime createTime;
}
```

### 3. 联表查询

当需要查多张表时，用 XML 写 SQL：

```xml
<!-- resources/mapper/ProductMapper.xml -->
<select id="selectProductWithCategory" resultType="xxx">
    SELECT p.*, c.name as category_name
    FROM sys_product p
    LEFT JOIN sys_category c ON p.category_id = c.id
    WHERE p.id = #{id}
</select>
```

## 常见错误排查

### 1. 端口被占用

```
Port 8080 was already in use
```

**解决**：
```bash
# 找到占用端口的进程
lsof -i:8080

# 杀掉它
kill -9 <PID>
```

### 2. 数据库连接失败

```
Connection refused
```

**解决**：
- 检查 MySQL 是否启动：`mysql -u root --socket=/tmp/my.sock`
- 检查 `application.yml` 的端口和密码

### 3. Token 无效

```
Token 无效或已过期
```

**原因**：
- Token 过期了（超过 7 天）
- Token 被篡改了

**解决**：重新登录获取新 Token

### 4. 编译报错

```bash
# 清理重新编译
mvn clean compile
```
